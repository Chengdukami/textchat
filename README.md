# 截图答题助手

一个同时支持 Windows 和 macOS 的 Electron 最小版本。

## 运行

```bash
npm install
npm start
```

首次打开设置窗口，填写 API 地址、模型名称和 API Key。
设置窗口会在程序启动时打开一次；之后可以从托盘菜单再次打开。API Key 会优先使用系统安全存储。
设置窗口中的“打开调试窗口”会显示请求地址、模型、截图数量、HTTP 状态、AI 原始响应和解析结果。

## 快捷键

- 左方向键：截取主屏幕并暂存
- 上方向键：把暂存的所有截图发送给 AI
- 下方向键：切换左下角答案的显示/隐藏

成功返回答案后，本轮暂存的截图会自动清空，避免下一轮题目和上一轮混在一起。

右方向键暂时没有绑定功能。托盘菜单里的“清空截图”用于手动清空本轮截图。

## 权限

macOS 需要给应用授予“屏幕录制”权限；如果系统不允许全局方向键监听，还需要在“隐私与安全性”里允许输入监控或辅助功能权限。
